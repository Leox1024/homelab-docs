# Homelab Docs

An interactive map of my homelab: network, power, servers and storage, with failure simulations.

**Live:** https://docs.leox.me

Flows and pulses are illustrative, not live data.

## Run locally

Open `index.html` in a browser.

## Edit

- `js/data-topology.js` — devices and cables
- `js/data-model.js` — workloads, VLANs and failure scenarios
